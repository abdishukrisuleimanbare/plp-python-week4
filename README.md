# Week 3 Assignment: Conditions and Loops

This repository contains my Week 3 Python assignment on conditions and loops.

* `grade_reporter.py` — Uses a `for` loop and conditional statements to assign grades, count passes and failures, and calculate the average score.
* `bug_hunt.py` — Fixes three bugs in a `while` loop program and calculates the sum of the numbers from 1 to 5.
* `screenshots/` — Contains screenshots showing both programs running successfully.

The hardest bug to find was the loop condition because the program could run without producing an error message, but it stopped before adding the number 5. I knew something was wrong because the program produced an incorrect answer instead of the expected result of 15.
